This repository does not implement a centralized configuration system. There is no dedicated config directory, no .env files, no application.properties, no YAML/TOML configuration files, and no runtime configuration loader. Each game is a standalone HTML5 application with its settings defined inline as JavaScript objects within the source files (e.g., `PLANET_CONFIG` in `src/science/gesture-cosmos/scenes/scene-neon-planets.js`, Phaser `config` objects in `src/literacy/movespelling/js/main.js`, and per-game config objects in Chinese games). Build-time configuration is minimal — only `vite.config.js` and `package.json` exist at the monorepo root, handling build inputs, static asset copying, and script aliases. Game-specific data lives alongside each game's source (e.g., `src/data/vocabulary.md`, `src/literacy/movespelling/assets/data/words.json`, `src/data/curriculum-map.json`). There is no mechanism for environment-based overrides, feature flags, or secrets management.
