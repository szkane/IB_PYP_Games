Single-page app loaded from `index.html` via a single ES module entry (`js/main.js`). The runtime is split into thin orchestration layers and two self-contained game modules:

- Orchestration layer: `router.js` (hash-based routing over `#/g/:grade/:cat/:mode/play`), `main.js` (audio unlock on first gesture + route→screen dispatch), `screens.js` (renders home/categories/mode-select/play screens and owns the current game instance lifecycle via `destroyCurrentGame()`), `progress.js` (localStorage-backed per-grade/category stars), `data.js` (auto-generated vocab lists, grade metadata, `WordUtil.gridChars/isGridUsable/pickRound`), `audio.js` (SpeechSynthesis + SFX wrapper), `voice-control.js` (accent switcher UI).
- Game layer: `js/wordsearch/controller.js` (`WordSearchGame`) and `js/crossword/controller.js` (`CrosswordGame`). Each controller owns its own DOM subtree, injects a scoped `<style>` block once, and exposes `start()` / `destroy()`. Controllers are instantiated by `screens.renderPlay`, receive `onComplete`/`onFound`/`onBack` callbacks, and never import each other.
- Algorithmic helpers live in sibling files: `wordsearch/grid.js` (grid generation) and `crossword/generator.js` + `crossword/layout.js` (sparse grid placement → numbered across/down layout). Controllers import these helpers but not each other, keeping the two games decoupled.
- Styling is global (`css/style.css`) plus per-game injected CSS; there is no build step — the app runs directly from the file tree.
