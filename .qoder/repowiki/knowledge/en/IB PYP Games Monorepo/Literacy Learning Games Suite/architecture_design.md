The `src/literacy/` directory is a flat portfolio of independent single-page apps — `mc_words`, `movespelling`, and `wordquest` — each with its own `index.html`, `css/`, and `js/` tree and no shared runtime code. Cross-child cohesion comes from: (1) a unified Minecraft asset theme under `mc_words/res/images/` whose category folders (`Animal`, `Block`, `Enemy`, `Passive`, …) are referenced by all three games for consistent visuals; (2) a shared TTS pronunciation entry point used by both `mc_words` and `wordquest`; (3) the sibling `g1_*.html` pages that act as landing/navigation frames linking into the three sub-apps. There is no build pipeline or inter-app communication — each game is self-contained and served statically.
