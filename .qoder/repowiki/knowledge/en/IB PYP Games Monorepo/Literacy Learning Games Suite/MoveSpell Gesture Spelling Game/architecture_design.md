Single-page static HTML5 app loaded from `index.html`, which wires three CDN libraries (MediaPipe Hands, Phaser 3) and then loads the module tree in dependency order: `js/core/hand-tracker.js` and `js/core/audio-manager.js` first, followed by `js/game/spawner.js`, `scene-setup.js`, `scene-play.js`, `scene-results.js`, and finally `js/main.js`. `main.js` is the sole entry point — it requests camera permission, initializes `HandTracker` and `AudioManager`, fetches `assets/data/words.json`, bootstraps a transparent Phaser.Game with scenes `[SetupScene, PlayScene, ResultsScene]`, and publishes hand events (`handUpdate`, `handStateChange`) via `game.events` so scenes stay decoupled from MediaPipe. `core/` holds cross-cutting concerns (gesture state machine + Web Speech API TTS), `game/` holds one class per scene plus the pure-function `Spawner` (distractor generation + spawn-position layout), and `assets/` keeps data and media separate from code. The camera feed renders as a full-screen mirrored `<video>` behind the transparent canvas; a CSS `#hand-cursor` div mirrors the tracked palm position for smooth cursor rendering.
