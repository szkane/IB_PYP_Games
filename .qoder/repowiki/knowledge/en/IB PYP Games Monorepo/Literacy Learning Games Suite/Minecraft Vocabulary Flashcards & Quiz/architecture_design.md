Single-page vanilla JS application loaded by `index.html`, which wires the DOM shell (top nav, card grid, quiz overlay, error modal) to two scripts: `js/data.js` exposes the static data layer (`WORDS_DATA` keyed by scene id, `SCENES` listing all 13 categories), and `js/app.js` owns all runtime state in a single `currentState` object plus a nested `quiz` sub-state. Rendering is imperative — `renderHomePage()` / `renderScenePage()` clear and rebuild the `#cardGrid`; there is no framework or component model. The app has two views (home scene list vs. per-scene word cards) plus an overlay-driven quiz mode that masks letters based on a difficulty config (`QUIZ_DIFFICULTIES`). Audio uses the Web Speech API (`speechSynthesis`) with US/UK accent toggling; images are served from `res/images/<Scene>/` matching each word's `file` field. No build step — assets are referenced directly via relative paths.
