The repo is a Vite-based build orchestrator around four sibling game packages (`src/literacy`, `src/math`, `src/science`, `src/chinese`) plus a `src/uoi` lane. A single `vite.config.js` discovers every `.html` entry under `src/`, externalizes CDN imports (Three.js, https URLs), and copies per-game `js/`, `css/`, `assets/`, `res/` trees into `dist/`. The `scripts/generate-index.js` prebuild step reads `src/data/curriculum-map.json`, scans the filesystem for game pages, normalises titles, emits `src/index.html` as the grade/unit/subject learning map, and rewrites `src/sw.js` with an up-to-date cache version and precache URL list. `scripts/qa-curriculum.js` enforces cross-child contracts: every mapped path must exist, every generated link must be present in both the index and the service worker, each game page must carry its own embedded `<style>` + `<script>` (no external CSS/JS), include a viewport meta tag, a `pyp-map-link` return link pointing at the correct relative `index.html`, and meet touch-target/media-query baselines. The root `index.html` is a thin redirect to `src/index.html`. This makes the curriculum map the single source of truth that wires all children together at build time.
