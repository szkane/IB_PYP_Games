The module is a flat collection of three self-contained single-page applications — each file is an independent `<!doctype html>` document with its own `<style>` block, inline `<script>`, and embedded curriculum data. There is no shared code or build step between them; they are served directly by the web server.

- `g1_chinese-practice-print.html`: A print-worksheet generator built around a left control panel (course selector, textarea inputs for characters/words, grid-type/color/font options) and a right A4 preview rendered as CSS Grid cells (`tianzige` / `mizige`). It loads `pinyin-pro@3.19.0` from jsDelivr to auto-generate pinyin above characters and uses `window.print()` plus `@media print` rules to produce multi-page PDFs. Course content is stored in a large `courseData` object keyed by `1a-1`, `1b-yy2`, etc., covering Grade 1–2 textbooks including 语文园地 sections.
- `g1_pinyin_training.html`: A mobile-first card-and-quiz app styled with Tailwind CDN. Data lives in a `data.two/three/whole` array of `{py, char, rule, type, tts}` entries; a `generateQuizData()` normalizes accented vowels into clickable letter buttons and drives a Web Speech Synthesis quiz loop.
- `g1_word_spinner.html`: A GSAP-animated canvas wheel that rotates through six radicals per selected 字族 (stored in `CHAR_FAMILIES`), revealing a combined character via a lookup table. Layout uses CSS Grid with claymorphism tokens in `:root` variables.

All three pages share a common navigation footer `<a class="pyp-map-link" href="../index.html">PYP Map</a>` injected at the bottom of each file.
